### Шаг 4. Несколько потоков

**Наблюдение:**

При использовании нескольких потоков вычисления выполняются одновременно. Это позволяет задействовать несколько логических процессоров и увеличить общую загрузку CPU по сравнению с одним потоком.

Фактическая загрузка зависит от характеристик процессора и других запущенных программ.

**Что происходит с загрузкой CPU при увеличении количества одновременно работающих потоков?**

При увеличении количества потоков загрузка процессора обычно возрастает, поскольку больше логических процессоров одновременно выполняют вычисления.

**Почему после некоторого количества потоков дальнейшее увеличение не обязательно продолжает повышать загрузку?**

Количество вычислительных ресурсов процессора ограничено. Когда все доступные логические процессоры уже загружены, добавление новых потоков не обязательно увеличивает производительность. Потоки начинают конкурировать за вычислительные ресурсы, поэтому прирост загрузки становится незначительным.

### Итоговый вопрос

**У компьютера 4 физических ядра и 8 логических процессоров. Программа сообщает Environment.ProcessorCount == 8. Почему это не противоречие?**

Это не противоречие, потому что физические ядра и логические процессоры — разные понятия. Одно физическое ядро может поддерживать два логических потока. Поэтому процессор с четырьмя физическими ядрами может предоставлять операционной системе восемь логических процессоров.


### Контрольные вопросы

**1. Что показывает Environment.ProcessorCount?**

Показывает количество логических процессоров, доступных текущему процессу .NET.

**2. Чем физическое ядро отличается от логического процессора?**

Физическое ядро — это реальная вычислительная часть процессора. Логический процессор — это вычислительный поток, который операционная система видит как отдельный ресурс для выполнения задач.

**3. Почему увеличение количества потоков может увеличить загрузку CPU?**

Потому что несколько потоков могут выполнять вычисления одновременно, используя разные логические процессоры.

**4. Почему после некоторого количества потоков загрузка не обязательно продолжает расти?**

Потому что количество вычислительных ресурсов процессора ограничено. Когда они уже полностью загружены, дополнительные потоки не дают существенного увеличения общей загрузки.

**5. Почему частота процессора может изменяться во время работы?**

Современные процессоры автоматически регулируют частоту в зависимости от нагрузки, температуры и энергопотребления.
